How it works

Powerful processing, zero servers.

FileForge ships the entire processing pipeline to your browser. Here is what happens when you use it.

01

Choose a tool

Open any utility from the grid above. Each is a self-contained page with exactly the controls you need and nothing else.

02

Drop your files

Drag, drop or browse. Files are read straight from disk into browser memory via the File API — no network request is ever made.

03

Download results

Canvas, Web Audio, pdf-lib and FFmpeg.wasm do the heavy lifting locally. Grab the output instantly, even offline.

Privacy by architecture

Your files never leave your device.

Most online converters upload your documents to a server, process them, and hope you forget about it. FileForge physically cannot do that — there is no backend, no database and no login. Open your browser's network tab while you work: the only requests are the ones that loaded the app itself.

  • No uploads

    Files are read locally via the File API and never transmitted.

  • Works offline

    Once loaded, every tool keeps working without a connection.

  • Native speed

    WebAssembly and Web APIs run at near-native performance.

  • No sign-up

    No accounts, emails, cookies or analytics — just tools.
