About the Spreadsheet Export

Export Excel data to CSV or JSON without opening Excel — or uploading the file. Workbooks are parsed locally with SheetJS: pick any sheet from the workbook, preview the data as a table, and export clean CSV with proper quoting, or JSON with typed values (numbers as numbers, dates as dates).

It is the developer-and-analyst convenience tool: getting data out of a workbook a colleague sent, feeding a script, importing into a database, or just reading an XLSX on a machine without Office. The workbook never leaves your device — SheetJS reads it in memory and the export is generated on the spot.

How to use it

  1. 1

    Drop your workbook

    Add an .xlsx, .xlsm or .xls file — every sheet is detected automatically.

  2. 2

    Pick a sheet

    Switch between sheets and preview the rows before exporting.

  3. 3

  4. 4

    Save the output file — parsed and generated entirely on your machine.

Frequently asked questions

Can I convert XLSX to CSV without Excel installed?

Yes — that is exactly what this tool is for. The workbook is parsed in your browser with SheetJS, so any device with a browser can produce the CSV.

How are multiple sheets handled?

Every sheet in the workbook is listed; you preview and export them one at a time, so each CSV stays clean and single-table.

Does it export JSON too?

Yes. JSON output preserves data types — numeric columns become numbers, dates become dates — which makes it directly usable in scripts and APIs.

Is my spreadsheet uploaded anywhere?

No. Parsing and export happen in browser memory. This makes it appropriate for financial data and other confidential workbooks.
